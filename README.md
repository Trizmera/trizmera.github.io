# 🏰 Beatriz Cruz - Portfolio & CV Website

A medieval-themed CV website with Old English flair and 90s nostalgia. Built with pure HTML and CSS.

## 🎨 Features

- **Medieval Aesthetic** - Stone textures, 3D borders, and Old English vocabulary
- **Fully Responsive** - Mobile-friendly flexbox layout
- **SEO Optimized** - Meta tags, Open Graph, JSON-LD structured data
- **Four Sections**:
  - 🏠 Manor (Home) - Professional summary
  - 📜 Chronicles (Experience) - Work history
  - ⚔️ Arts & Crafts (Skills) - Technical expertise
  - ✉️ Missives (Contact) - Contact information

## 🛠️ Technologies

- HTML5
- CSS3 (Flexbox)
- Medieval vibes ✨

## 📦 Structure

```
.

```
